Ready-to-copy CFW pack for **stock (4GB RAM) Nintendo Switch** consoles
— Erista, Mariko, Lite, or OLED without a RAM upgrade.

Built entirely from official upstream source code and official releases
of each individual project — no binaries copied from pirate packs.

## Quick install

1. Download this repository's contents.
2. Copy everything to the root of your SD card (merge with existing
   content, overwriting is expected).
3. Inject `hekate_ctcaer_6.5.3.bin` via RCM.
4. In the Hekate menu, pick `Atmosphere (emuMMC)` or
   `Sistema Original (Stock)`.

## What's included

Hekate 6.5.3 + Atmosphère 1.11.2 (both compiled from official source),
Ultrahand Overlay (Tesla Menu replacement, with Portuguese translation),
Status Monitor, sys-clk, MissionControl, emuiibo, Fizeau, sys-tune,
MasterVolume, sys-con, SysDVR, SaltyNX, FPSLocker, ReverseNX-RT
(translated to Portuguese), EdiZon, JKSV, sphaira, DBI, NX-Activity-Log,
HekateToolbox, Moonlight-Switch, NXThemesInstaller, hbmenu, plus RCM
payload tools (TegraExplorer, DowngradeFixer, prodinfo_gen).
