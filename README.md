Pacote de CFW pronto pra copiar no cartão SD, pra consoles **Nintendo
Switch de fábrica (4GB de RAM)** — Erista, Mariko, Lite ou OLED sem
upgrade de memória.

Montado 100% a partir de código-fonte oficial e releases oficiais de
cada projeto — nenhum binário vem de pack pirata.

## Instalação

1. Baixe a versão mais recente na aba **[Releases](../../releases/latest)**
   deste repositório.
2. Extraia o `.zip` baixado.
3. Copie o conteúdo extraído pra **raiz do cartão SD**, mesclando com o
   que já existir (sobrescrever é esperado).
4. Ligue o console normalmente — se o seu Switch já tem **modchip**
   (picofly, hwfly, etc), ele injeta o CFW sozinho no boot, sem precisar
   de RCM manual.

## O que está incluído

Hekate 6.5.3 + Atmosphère 1.11.2 (compilados do código-fonte oficial),
Ultrahand Overlay (substitui o Tesla Menu, com tradução em português),
Status Monitor, sys-clk, MissionControl, emuiibo, Fizeau, sys-tune,
MasterVolume, sys-con, SysDVR, SaltyNX, FPSLocker, ReverseNX-RT
(traduzido pra português), EdiZon, JKSV, sphaira, DBI, NX-Activity-Log,
HekateToolbox, Moonlight-Switch, NXThemesInstaller, hbmenu, além de
payloads de manutenção (TegraExplorer, DowngradeFixer, prodinfo_gen).
